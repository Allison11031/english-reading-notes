# 英文閱讀筆記

把紙本英文閱讀的學習過程，變成可以查詢、分類與回顧的個人資料庫。

這是一個手機和電腦都能使用的網頁小程式。閱讀紙本教材時，只要輸入不懂的單字或片語，程式就會儲存紀錄並查詢解釋；閱讀理解筆記也能依書名和篇名集中管理。

## 為什麼做這個專案

重新閱讀以前的英文教材時，每讀完一篇都會留下生字、片語和自己的理解。但紙本筆記不容易搜尋，查字典和整理筆記也會中斷閱讀。

因此，我希望有一個工具能做到：

- 不用掃描整本書，只記錄真正需要的內容
- 輸入單字或片語後自動查詢，節省手動翻譯時間
- 依閱讀篇章或首字母回顧紀錄，不用打開試算表
- 優先使用免費字典，只有需要時才使用 AI，控制 API 額度

## 主要功能

### 新增紀錄

- 先設定並鎖定書名與篇名，同一篇不用重複輸入
- 依輸入內容自動判斷單字或片語，查詢前可手動切換
- 按一次「查詢並儲存」，先保存輸入內容，再查詢字典與翻譯
- 單字有多種詞性時，全部顯示，不需要手動選擇
- 同一個字已有紀錄時會提醒，也可以另存到目前篇章
- 可在查詢結果下方補充「我的註解」，離開欄位後自動儲存
- 閱讀理解筆記可記錄段落或主題、自己的理解、原文句子與疑問

### AI 解析

- 只有按下「AI 解析」才會呼叫 AI
- AI 結果獨立顯示及儲存，不會覆蓋字典內容
- 不需要原文句子也能解析；有原文句子時，會補充它在句子中的意思
- 同一筆紀錄和同一句原文會沿用已有結果，避免重複使用額度
- 內建每日使用上限與 AI 使用紀錄

### 查看紀錄

- 可搜尋單字、片語、解釋、原文句子與筆記內容
- 可依書名和類型篩選
- 支援閱讀篇章、首字母、最新新增三種排序
- 依閱讀篇章查看時，可收合篇章；依首字母查看時，可跳到指定字母
- 手機點開後進入詳細頁，電腦以左右兩欄顯示列表與內容
- 可在紀錄頁修改單字和片語的「我的註解」

## 系統流程

```mermaid
flowchart TD
    A[使用者輸入單字或片語] --> B{已有相同紀錄?}
    B -- 是 --> C[顯示舊筆記<br/>可另存到目前篇章]
    B -- 否 --> D[先寫入 Google 試算表]
    D --> E[查詢免費字典 API]
    E --> F[Google 翻譯補中文]
    F --> G[更新紀錄並顯示結果]
    G --> H{使用者按下 AI 解析?}
    H -- 否 --> I[補充我的註解(選填)]
    H -- 是 --> J[檢查快取與每日上限]
    J --> K[呼叫 Gemini API]
    K --> L[寫入 AI解析 欄位<br/>字典結果保持不變]
```

## 使用技術

| 項目 | 技術 |
|---|---|
| 前端 | HTML、CSS、JavaScript |
| 後端 | Google Apps Script |
| 資料儲存 | Google 試算表 |
| 字典資料 | [Free Dictionary API](https://github.com/meetdeveloper/freedictionaryapi) |
| 中文翻譯 | Apps Script `LanguageApp` |
| AI 解析 | Gemini API，預設模型為 `gemini-3.5-flash-lite` |

## 資料結構

| 工作表 | 用途 |
|---|---|
| `單字` | 單字、音標、解釋、例句、原文句子、註解、AI 解析等 |
| `片語` | 片語、解釋、例句、原文句子、註解、AI 解析等 |
| `閱讀理解` | 段落或主題、我的理解、原文句子、疑問 |
| `設定` | 上次的書名與篇名、AI 模型、每日上限與當日使用次數 |
| `AI使用紀錄` | AI 呼叫時間、用途、內容與結果 |

程式會自動建立工作表。更新版本時只會在既有工作表後方補上新欄位，不會刪除舊資料。

## 設計重點

### 先存再查

字典或翻譯失敗時，使用者輸入的內容仍會保留。網路中斷後重新送出，也會沿用同一個紀錄編號，避免產生重複資料。

### AI 不取代字典

字典結果與 AI 結果分開保存，方便判斷資料來源，也避免原始查詢結果被覆蓋。

### 由使用者決定何時使用 AI

查詢固定使用字典和翻譯，AI 只由按鈕觸發，讓 API 使用次數清楚可控。

### 從實際使用調整介面

查詢結果最初使用可編輯欄位，後來改成閱讀版面，讓「查到的資料」和「自己要寫的筆記」更容易區分。三個輸入分頁也整併成兩個，單字和片語改由程式輔助分類。

## 安裝與部署

### 1. 建立專案

1. 建立一份 Google 試算表。
2. 選擇「擴充功能」>「Apps Script」。
3. 將 `Code.gs` 的內容貼到預設程式檔。
4. 新增名為 `Index` 的 HTML 檔，貼上 `Index.html` 的內容。

### 2. 部署網頁

1. 選擇「部署」>「新增部署作業」。
2. 類型選擇「網頁應用程式」。
3. 「執行身分」選擇「我」，「誰可以存取」選擇「只有我」。
4. 完成授權後，開啟部署網址。

### 3. 設定 AI 解析（選用）

1. 到 Google AI Studio 建立 Gemini API 金鑰。
2. 在 Apps Script 的「專案設定」>「指令碼屬性」新增：

```text
GEMINI_API_KEY = 你的金鑰
```

未設定金鑰時，字典查詢和其他功能仍可使用。請勿把金鑰寫進程式碼或提交到 GitHub。

## 目前限制

- 目前為個人使用設計，部署權限設定為「只有我」
- 字典查詢依賴第三方服務，片語收錄可能不完整
- 紀錄頁會一次讀取全部資料，紀錄量很大時可能變慢
- 解釋內容目前不能在小程式中編輯，需要時可修改試算表
- 尚未加入自動化測試流程
